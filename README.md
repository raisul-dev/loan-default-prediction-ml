# SME Loan Default Prediction

A machine learning project for predicting loan defaults using Python and Scikit-learn.

## Project Overview

The goal of this project is to predict whether a customer is likely to default on a loan.

## What I Worked On

- Exploratory Data Analysis (EDA)
- Data Cleaning
- Feature and Target Selection
- Train/Test Split
- Logistic Regression
- Confusion Matrix
- Precision, Recall and F1-score
- Probability Prediction
- Decision Threshold Analysis
- Decision Tree
- Overfitting Analysis

## Models

- Logistic Regression
- Decision Tree Classifier

## Key Learning

One of the main things I learned from this project is that accuracy alone can be misleading when the dataset is imbalanced.

I also learned how precision, recall, F1-score, threshold selection and overfitting help us understand a classification model better.
